# sp500-backtesting-strategy
Python backtest of a 200-day moving average trading strategy on the S&amp;P 500, compared against a Buy &amp; Hold benchmark.
This project evaluates a 200-day moving average trading strategy
using historical S&P 500 data.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
- Jupyter Notebook

## Strategy
The strategy uses the 200-day moving average to determine when to
remain invested in the S&P 500 and when to move to cash.

## Performance
The strategy is compared against a Buy & Hold benchmark using
historical returns and maximum drawdown.

## Limitations
The backtest does not account for taxes, slippage, bid-ask spreads,
or execution delays.
